## Description

Introduce three new localized strings consumed by the router error screen in Task 002. The keys are added to all three ARB files in the same edit (gen-l10n errors out if any locale is missing a key). After ARB edits, run `flutter gen-l10n` so the abstract `AppLocalizations` class and its three concrete subclasses gain matching getters. Commit ARB and generated files together (per `docs/features/i18n.md` line 156).

This is a pure infrastructure task: no Dart consumer of the new keys exists yet (Task 002 introduces the consumer). `dart analyze` after gen-l10n must still pass — the new getters are unused at this stage, which is fine for generated `app_localizations*.dart` files (the project's `analysis_options.yaml` does not flag unused generated getters).
